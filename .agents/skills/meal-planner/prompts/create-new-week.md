# Prompt: создать план на новую неделю

## Контекст

Пользователь просит создать план на следующую неделю с учётом текущих остатков.

## Шаги

### 1. Найти последнюю неделю
```bash
ls -la plans/week_*.json | tail -1
```

### 2. Прочитать профиль и нормы
- `data/user_profile.json` — антропометрия, аллергии, тренировки
- `data/nutrition_norms.json` — цели КБЖУ
- Текущий план (последний `week_*.json`)

### 3. Спросить пользователя:
- Какие остатки есть от прошлой недели? (Milky Way осталось N шт, печень в морозилке 240г, и т.д.)
- Какие изменения хочет? (другая рыба вместо скумбрии, больше курицы, etc.)
- Цены изменились? (например клубника по-прежнему 1499₽/кг?)

### 4. Создать новый JSON

```python
import json
from pathlib import Path

old = json.loads(Path("plans/week_2026-W21.json").read_text(encoding="utf-8"))

# Update
old["week_id"] = "2026-W22"
old["start_date"] = "2026-05-25"
old["end_date"] = "2026-05-31"
old["actual_orders"] = []  # очищаем — заполнится после доставки

# Update stock_at_home (вычесть использованное на прошлой неделе)
old["stock_at_home"] = [
    # пример: Milky Way всё съел → удалить
    # печень осталась 240г → добавить
    {"ref": "local:liver_severnaya", "qty_g": 240, "note": "Из морозилки от прошлой Вс"},
]

Path("plans/week_2026-W22.json").write_text(
    json.dumps(old, ensure_ascii=False, indent=2), encoding="utf-8"
)
```

### 5. Прогнать и проверить

```bash
python -m meal_planner all plans/week_2026-W22.json
```

Покажи пользователю:
- Output of `report` (КБЖУ по дням, бюджет)
- Output of `validate` (errors/warnings)

### 6. Если есть warnings — обсудить с пользователем

Например:
- «Бюджет 6300₽ > 6000 — урезать что-то или OK?»
- «Печень всё ещё содержит молочку йогурт — заменить на оливковое масло?»
- «Белок 105г vs цель 161 — добавить +1 уп творога в офисные дни?»

### 7. Если ОК — сообщить пользователю

```
✓ План на 2026-W22 создан: plans/week_2026-W22.json
✓ Бюджет: 5800₽ ≤ 6000 ✓
✓ КБЖУ среднее: 2410 ккал (цель 2455) ✓
✓ Список покупок: output/shopping_list.csv (28 позиций)
✓ HTML: output/weekly_plan.html

Готов к заказу в 5ka.ru.
```
