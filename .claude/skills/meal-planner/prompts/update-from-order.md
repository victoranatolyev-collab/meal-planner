# Prompt: внести факт-заказ и сверить с планом

## Контекст

Пользователь получил доставку из Пятёрочки и прислал скриншоты заказа из приложения (или открытый URL).

## Шаги

### 1. Извлечь данные из заказа

Скриншоты/страница содержат:
- Номер заказа (1482444937)
- Дата доставки
- Сумма к оплате (factual, не плановая!)
- Список товаров: `{name, qty, unit, price_per_unit, total}`
- Сборка/упаковка, экономия

**Важно:** в приложении iPhone цены и веса корректны (взвешивание после), на сайте 5ka.ru могут быть устаревшие.

### 2. Прочитать актуальный план

```bash
cat plans/week_2026-W21.json | python -m json.tool | head -50
```

### 3. Добавить заказ в `actual_orders[]`

Открой `plans/week_2026-W21.json` и добавь:

```json
"actual_orders": [{
  "shop": "Пятёрочка",
  "order_id": "1482444937",
  "delivered_at": "2026-05-17T22:23:00+03:00",
  "paid_rub": 5062.01,
  "sum_before_discount": 5268.64,
  "packing_fee_rub": 39.00,
  "delivery_fee_rub": 0,
  "discount_rub": 245.63,
  "items": [
    {"plu": "3191298", "name": "Грудка куриная охлажденная", "qty": 1.6, "unit": "кг", "price_per_unit": 239.99, "price_rub_total": 384.00},
    ...
  ]
}]
```

### 4. Запустить order-match

```bash
python -m meal_planner order-match plans/week_2026-W21.json
```

Output покажет:
- ❌ Missing: что в плане не куплено
- ➕ Extra: что куплено не по плану
- ⚖️ Qty diff: расхождение по граммам >15%
- 💰 Price diff: расхождение по цене >20%
- 💰 Итог: план vs факт сумма

### 5. Обсудить с пользователем критичные расхождения

**Missing — серьёзно, нужно решение:**
- Если отсутствует базовый ингредиент Main A (курица, рис, морковь по-кор., кимчи) → план не выполним
- Предложить: докупить в ближайшую Пятёрочку или адаптировать рецепты

**Extra — обычно ок, но обратить внимание:**
- Если куплены продукты вне плана — могут пригодиться или испортятся

**Qty diff >50%:**
- Если меньше плана → может не хватить на все приёмы недели
- Если больше → запас на следующую неделю (зафиксировать в `stock_at_home` для след. плана)

**Price diff:**
- Если переплата →100₽ за позицию → пометить «купить дешевле в след. раз»

### 6. Обновить план если нужны корректировки

Например, если купили скумбрию копчёную вместо сырой:
- Изменить рецепт `main_b` в `data/dishes_library.json` (готовка → ready_to_eat)
- Уменьшить порцию в `main_b` если уп. меньше (300г вместо 500г → 75г × 4 вместо 100г × 5)
- Перегенерить: `python -m meal_planner all plans/week_2026-W21.json`

### 7. Сообщить пользователю результат

```
✓ Заказ 1482444937 учтён, оплачено 5062.01₽
⚠️ Расхождения с планом:
  - Клубника по 1499₽/кг вместо плановых 100₽/кг (+540₽)
  - Скумбрия копчёная вместо сырой → готовку отменить
  - Печень Северная 650г вместо Петелинка 450г → +200г запас
  
Рекомендации:
  - В следующий раз клубнику только при скидке ≤200₽/кг
  - На след. неделю печени половина уже есть → −200₽ в закуп
```
