# Prompt: проверить текущий план на правила

## Контекст

Пользователь хочет убедиться, что текущий план соблюдает все правила (КБЖУ, бюджет, железо, C1, и т.д.).

## Шаги

### 1. Найти текущий план
```bash
ls plans/week_*.json | sort | tail -1
```

### 2. Запустить валидатор
```bash
python -m meal_planner validate plans/week_2026-W21.json
```

### 3. Также показать report для контекста
```bash
python -m meal_planner report plans/week_2026-W21.json
```

### 4. Интерпретация для пользователя

**🔴 Errors (нужно исправить):**
- `iron_meal_no_dairy` → молочка в Вс железных приёмах. Заменить йогурт в пюре на EVOO 5мл + лимон. Хвост Россия тёмный 75г обязательно.
- `unresolved_ref` → опечатка в `dish_id` или `ref`, не найдено в каталоге. Проверить написание.

**🟡 Warnings (рассмотреть):**
- `kbju_daily_kcal` (>10% deviation) → подкрутить порции в этот день
- `kbju_daily_protein` (<70% target) → +1 уп творога / больше курицы
- `kbju_weekly_protein_avg` (<80%) → системно — пересмотр Main A порции вверх
- `c1_sweet_breakfast` → если сладкий завтрак с сладким хвостом — убрать хвост или добавить тег `c1_exclusion`
- `protein_chicken_4days` → курица меньше 4 дней — добавить
- `ll_count_3max` → ЛЛ десертов >3 — урезать (например Вс → домашний)
- `budget` → бюджет превышен — найти где сократить (клубника, курица кубики, и т.д.)

### 5. Предложить пользователю исправления

Не делать самовольно — спросить:
```
Найдено 2 errors и 11 warnings. Хочешь, чтобы я:
[1] Исправил iron-meal: заменил йогурт в Main C на EVOO + лимон
[2] Добавил творог 180г в Вт/Ср/Пт обеды для +60г белка/нед
[3] Урезал ЛЛ-десерты: Вс заменить на домашний с творогом+клубникой
[4] Ничего, оставить как есть
```

### 6. После исправления — перегенерить
```bash
python -m meal_planner all plans/week_2026-W21.json
```

И показать новый validation report.
