## Структура плана

План делится на **фазы** (Phase 1, 2, ...). Каждая фаза — крупный самодостаточный блок работ.

Внутри каждой фазы — задачи, привязанные к `feature_id` из `ROADMAP.json`.

### Шаблон фазы

```markdown
### Phase N: <Название>

- [ ] `scr-Y` — Название скрипта
- [ ] *(non-feature task: e.g., настроить Docker compose)*

- ...
```
